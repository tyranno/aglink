aglink-web

Claude 가 브라우저 · Electron/Wails 앱 · 다른 VS Code 창을 텍스트로 읽고 조작하게 해 줍니다.

설치 프로그램이 이미 해 둔 것: 데몬 설치와 자동 시작, Claude Code 에 MCP 서버 aglink-web 등록, VS Code 확장 aglink-vscode 설치(VS Code 가 있을 때). 남은 건 크롬 확장 하나뿐입니다.

1크롬 확장 불러오기 (처음 한 번)

  1. 크롬 주소창에 chrome://extensions 를 입력합니다.
  2. 오른쪽 위 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다를 누르고 이 폴더를 고릅니다:
    %LOCALAPPDATA%\Programs\aglink-web\chrome-extension
    시작 메뉴 → aglink-web → "크롬 확장 폴더 열기" 로 바로 열 수 있습니다. 설치 폴더를 바꿨다면 그 아래의 chrome-extension 입니다.
  4. 크롬에 로그인돼 있어야 합니다. 확장은 로그인한 계정 이름으로 데몬에 붙습니다.

2업데이트할 때

새 설치 파일을 그냥 실행하면 됩니다. 끝나면 chrome://extensions 에서 aglink-web 카드의 새로고침(↻) 을 한 번 누르세요. 쓰던 Claude 세션은 새로 열어야 도구가 다시 붙습니다.

쓰는 법

Claude Code 에게 말로 시키면 됩니다. 도구는 이렇게 고릅니다:

list_profiles
  you@example.com | connected 3h ago | default          ← 크롬
  app:mytool | cdp:9222 | http://… | 1 window           ← Electron/Wails 앱
  vscode:backend@myserver | SSH myserver | /home/… | …  ← 다른 VS Code 창
대상도구예
크롬 탭get_page_text, click, type, list_elements …"열린 탭에서 결재 목록 읽어줘"
Electron/Wails 앱같은 도구 + profile="app:이름"앱을 디버그 포트로 띄워야 보입니다(아래)
다른 VS Code 창vscode_workspace, vscode_read, vscode_terminal_run …"backend 창에서 go test 돌려서 결과 알려줘"

연속 동작은 한 번에 — run_steps

"설정 열기 → 이름 입력 → 저장 → 저장됨 확인" 처럼 다음 동작이 정해져 있으면 Claude 가 단계마다 왕복하지 않고 한 번의 호출로 처리합니다. 크롬 탭과 Electron/Wails 앱 창 모두 같습니다. Claude 에게 "한 번에 해줘" 라고 하면 이 도구를 씁니다.

run_steps  profile="app:mytool"  snapshot="text"
  [{"tool":"click",  "selector":"text=설정"},
   {"tool":"expect", "selector":"role=dialog"},           ← 화면이 바뀔 때까지 기다림
   {"tool":"type",   "selector":"label=이름", "text":"홍길동"},
   {"tool":"click",  "selector":"role=button[name=\"저장\"]", "wait_ms":300},
   {"tool":"expect", "text":"저장됨"}]
  • 단계는 모든 도구를 쓸 수 있습니다. 추가로 wait(정해진 시간 대기)와 expect(요소가 보일 때까지, "gone":true 면 사라질 때까지 대기)가 있습니다.
  • 실패하면 그 단계에서 멈추고 몇 단계까지 됐는지 알려 줍니다. snapshot="text" / "elements" 를 주면 끝난(또는 멈춘) 화면 상태가 같은 응답에 붙습니다.
  • 전송·삭제·결제처럼 되돌릴 수 없는 마지막 동작은 배치 밖에서 따로 하게 되어 있습니다.

설치 옵션 (MCP 등록에 함께 들어감)

설치 파일에 아래 옵션을 주면 Claude Code 의 MCP 등록에 환경변수로 들어갑니다. 한 번 준 값은 기억되어, 다음 업데이트 때 다시 주지 않아도 유지됩니다(빈 값 /STEPDELAY= 로 지움).

옵션뜻
/STEPDELAY=200run_steps 단계 사이 기본 대기(ms). 화면 전환 애니메이션이 있는 앱이면 150~300.
/CDPPORTS=9222-9240,9333Electron/Wails 앱을 찾을 포트(기본값과 같음)
/INSECUREHOSTS=nas.local,10.0.0.5:8443인증서 경고를 자동으로 넘길 사내 호스트
aglink-web-Setup.exe /STEPDELAY=200 /INSECUREHOSTS=nas.local

이미 설치한 뒤라면 직접 바꿀 수도 있습니다: claude mcp remove aglink-web -s user 후 claude mcp add --scope user aglink-web -e AGLINK_WEB_STEP_DELAY_MS=200 -- "…\aglink-web.exe" mcp. 바꾼 값은 다음 호출부터 바로 적용됩니다(데몬 재시작 불필요).

Electron · Wails 앱을 다루려면

앱이 디버그 포트를 열고 떠 있어야 합니다(9222–9240 과 9333 을 찾습니다).

  • Electron: myapp.exe --remote-debugging-port=9222
  • Wails: 앱 코드의 Windows 옵션에 AdditionalBrowserArgs 한 줄이 필요합니다(환경변수로는 안 됩니다). 개발자에게 aglink 저장소의 web/README.md "앱 화면 다루기" 를 보여 주세요.

VS Code 창을 다루려면

설치 프로그램이 VS Code 확장을 깔아 두었습니다. VS Code 창마다 자동으로 붙어 list_profiles 에 vscode:… 로 나타납니다. Remote-SSH 창도 그대로 됩니다 — 확장은 이 PC 에서 돌고, 명령과 파일은 원격에서 처리됩니다.

창이 안 보이면: VS Code 출력 패널에서 "aglink" 를 골라 로그를 보세요. 한 번만 창에서 Ctrl+Shift+P → "Developer: Reload Window" 를 하면 대부분 해결됩니다.

주의: vscode_terminal_run 은 그 창의 권한으로 명령을 실행합니다(원격 창이면 원격에서). 창 설정에서 aglink.enabled 를 끄면 그 창은 연결되지 않습니다.

원격(SSH) 머신의 Claude 에서 쓰려면 (선택)

Claude Code 가 원격 리눅스에서 돌 때는, 이 PC 의 데몬 포트를 SSH 로 넘겨 주고 원격에 한 번 등록합니다.

# 이 PC 의 ~/.ssh/config — 해당 Host 항목에 한 줄
  RemoteForward 48219 127.0.0.1:48219

# 원격에서 한 번
claude mcp add --transport http --scope user aglink-web-remote http://127.0.0.1:48219/mcp

ExitOnForwardFailure yes 는 넣지 마세요 — 같은 호스트에 VS Code 창을 두 개 열면 두 번째 연결이 끊깁니다.

문제가 있을 때

  • 데몬 확인: 브라우저에서 http://127.0.0.1:48219/health → ok 가 나와야 합니다. 안 나오면 시작 메뉴에서 로그오프/로그온하거나 설치 파일을 다시 실행하세요.
  • Claude 에 도구가 안 보이면: 터미널에서 claude mcp list 로 aglink-web 이 있는지 보세요.
  • 제거: 설정 → 앱 → aglink-web. 사용자 설정(%USERPROFILE%\.aglink)은 남겨 둡니다.
