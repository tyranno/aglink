aglink-screen

Claude 가 윈도우 화면을 직접 조작하게 해 줍니다 — 창 목록, 접근성 트리로 읽기, 클릭·입력, 창 캡처.

설치 프로그램이 Claude Code 에 MCP 서버 aglink-screen 을 등록해 두었습니다. Claude Code 세션을 새로 열면 도구가 붙습니다. 따로 켜 둘 것은 없습니다 — Claude 가 필요할 때 띄웁니다.

언제 쓰나

  • 일반 윈도우 프로그램(탐색기, 설정, 사내 네이티브 앱 …)
  • 웹 페이지 · Electron/Wails 앱 · VS Code 창은 aglink-web 이 훨씬 가볍습니다 — 화면을 찍지 않고 텍스트로 읽기 때문입니다.

토큰을 아끼는 순서

  1. list_windows → snapshot (접근성 트리 — 글자로 읽음, 가장 쌈)
  2. invoke / set_value 로 좌표 없이 조작
  3. 그래도 안 되면 capture_window (이미지 — 가장 비쌈)

관리자 권한으로 뜬 프로그램

대상 앱이 관리자 권한이면 윈도우가 일반 프로그램의 클릭을 조용히 막습니다(UIPI). 결과에 경고가 붙으면 Claude Code 를 관리자 권한으로 실행해야 합니다.

원격(SSH) 머신의 Claude 에서 쓰려면 (선택)

Claude Code 가 원격 리눅스에서 돌 때 이 PC 의 화면을 쓰려면, 이 PC 에서 화면 서버를 띄워 두고 그 포트를 SSH 로 넘깁니다.

# 이 PC — 화면 서버 (창을 닫으면 꺼지므로 상시로 쓰려면 로그온 작업으로)
"%LOCALAPPDATA%\Programs\aglink-screen\aglink-screen.exe" serve

# 이 PC 의 ~/.ssh/config — 해당 Host 항목에 한 줄
  RemoteForward 48220 127.0.0.1:48220

# 원격에서 한 번 — 이름 끝의 -remote 는 "건너간 윈도우 PC 의 것" 이라는 뜻
claude mcp add --transport http --scope user aglink-screen-remote http://127.0.0.1:48220/mcp

업데이트 · 제거

  • 업데이트: 새 설치 파일을 실행하고, 쓰던 Claude 세션을 새로 여세요.
  • 도구가 안 보이면: claude mcp list 로 aglink-screen 확인.
  • 제거: 설정 → 앱 → aglink-screen.

화면을 조작하는 도구라, 쓰는 동안 마우스·키보드를 함께 움직이면 서로 방해합니다.
